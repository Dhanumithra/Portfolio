## 💻 Local Development Setup

To run the portfolio locally without build steps or external dependencies:

```bash
# Clone the repository
git clone https://github.com/Dhanumithra/Portfolio.git

# Navigate into the project folder
cd Portfolio

# Start a local HTTP server (Python 3)
python -m http.server 4321

# Or with Node.js npx
npx serve .
```

Open your browser and navigate to:  
👉 **`http://localhost:4321`**
